# ICT Concepts Backtest

A mechanical, rule-based backtest of **Inner Circle Trader (ICT)** concepts on
US index futures — **S&P 500 (ES)** and **Nasdaq 100 (NQ)** — across daily,
1-hour, and 5-minute timeframes.

The core strategy tested is the ICT playbook:

> **Liquidity sweep → Displacement → Fair Value Gap (FVG) re-entry**

## The strategy

**Long setup** (signal at the close of bar *t*; mirrored for shorts):

1. **Liquidity sweep** — within the last `sweep_lookback` bars, price wicked
   below the last confirmed swing low and closed back above it (a "stop hunt").
2. **Displacement** — bar *t−1* is a strong bullish candle (body ≥ `disp_atr` × ATR).
3. **FVG** — the displacement leaves a 3-candle bullish FVG, confirmed by bar *t*.
4. **Entry** — limit order at the FVG edge (fill at the open if a bar opens inside the zone).
5. **Stop** — beyond the sweep extreme (+ ATR buffer).
6. **Target** — the last confirmed swing high (the opposing liquidity pool).
7. **Filters** — minimum reward:risk (RR ≥ 1.0); optional premium/discount,
   market-structure (CHoCH/BOS), trend-alignment, and structure-break filters.

pip install pandas numpy matplotlib yfinance

## Run

Each runner fetches its data via `yfinance` on first run (cached to `data/`) and
writes outputs to its own results directory:

```bash
python run.py            # daily bars (2000–2026)            -> results/
python run_intraday.py   # 1-hour bars                       -> results_intraday/
python run_5m.py         # 5-minute bars (~60d) + randomization -> results_5m/
python run_reverse.py    # reverse-ICT control + randomization -> results_reverse/
```

The daily run is the primary study; the others reuse the same
`ict.py` / `strategy.py` / `engine.py` for cross-timeframe comparison.

## Execution model

Deliberately conservative:

- Signals at the close of bar *t*; entry order live from *t+1* for at most `max_wait` bars.
- Same-bar ambiguity (stop and target both touched) resolves to the **stop**.
- One position at a time, no pyramiding.
- Position size: fixed fractional risk — **1% of equity per trade**.
- Costs: round-trip bps of notional — ES 4 bps, NQ 8 bps (slippage + commission).

## Results (TL;DR)

The headline finding is a **negative result**: a mechanical daily-bar ICT
"sweep → displacement → FVG re-entry" model has **no robust edge** on ES/NQ over
2000–2026. It loses money in-sample and out-of-sample, on both symbols, across
every filter, exit-management rule, and parameter combination tested. Notably:

- The **liquidity-sweep filter is the weakest component** — dropping it is the only
  change that produces positive expectancy, and even that does not survive the IS/OOS split.
- The core problem is the **win rate** (~21–27%) against a ~2.3R target.
- The result is **parameter-insensitive** — not a tuning problem.
